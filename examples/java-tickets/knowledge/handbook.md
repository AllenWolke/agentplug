# 工单回复教学手册

## 登录问题

先确认问题发生时间、客户端版本、错误码以及是否能在另一浏览器复现。只索取脱敏截图和请求追踪编号，不索取密码、Token 或一次性验证码。将事实、推测和待确认项分别写入回复草稿。

## 重复问题

引用已有授权资料时保留资料来源和版本。历史草稿只作为参考，不证明当前工单具有同样原因。没有重现证据时提出最小验证步骤，不承诺已修复。

## 权限或数据问题

让用户说明期望操作和可见范围，通过组织规定的申请流程办理权限。不要建议绕过访问控制或直接修改数据库；需要转交时提出建议，不声称已自动重新指派。

## 回复格式

给出问题摘要、已有证据、建议验证步骤、需要用户补充的脱敏信息及知识引用。此示例生成草稿，不向外部工单系统提交任何变更。
