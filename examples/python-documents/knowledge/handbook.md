# 项目文档维护手册

文档负责人提交变更前，应核对接口版本、字段含义、示例以及相关权限说明。
平台的规范文档源保存在PostgreSQL中；pgvector索引是可重建的检索投影，不是独立的事实来源。

全量索引建立新的生成版本。只有所有批准文档的分块和向量成功写入并通过当前源版本与权限校验后，平台才切换活动版本。失败任务不得发布半成品索引。

增量同步根据规范源的连续变更事件处理新增、修改、权限变化和删除。删除文档留下版本化墓碑，检索不得返回已删除正文。源与事件在同一事务内提交，索引检查点只在对应投影完成后推进。

检索前同时核验用户与Agent机器身份；缓存命中仍核对当前文档权限、正文摘要以及活动索引版本。撤权不能被旧缓存恢复。

RAG评测的金标准与指标由平台冻结，业务Agent不接收金标准。检索指标包括Recall@K、Precision@K、MRR和nDCG。引用及完整回答另交独立评分器；内置词面蕴含仅是确定性基线，不能代表完整语义正确性。

缓存报告区分实际新增计费和节省估计。知识答案返回的usage只属于答案生成阶段；完整运行账单应查看平台账本，不累加重复HTTP回执。
