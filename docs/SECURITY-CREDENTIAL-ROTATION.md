# 凭证轮换与验证

平台、网关、数据库、模型供应商和各机器身份使用独立凭证。凭证仅通过私有配置、只读 Secret 文件或密钥管理系统注入，不保存到源码、日志、Trace 或公开验收报告。

已暴露凭证必须在签发端吊销并轮换；删除文件和加入 Git 忽略规则不能使旧值失效。轮换前盘点所有消费者与权限，使用经授权的新凭据验证调用，再撤销旧凭据并确认旧值返回未授权。加密数据主密钥需要解密、重新加密、版本控制及恢复演练，不能直接替换后丢弃旧密钥。

机器身份轮换不得扩大安装实例、能力或数据范围。撤销会话与 RefreshToken 后验证旧访问令牌和刷新均被拒绝；短期 access token 的验签不替代平台的当前授权判断。

公开前运行 `python scripts/scan_secrets.py`，同时检查 Git 历史、构建上下文和测试产物。公开扫描通过不代表签发端轮换已完成；真实环境的审计和轮换记录保存到受控位置。
