## 設定と配信

`python scripts/prepare_local_development.py` でパスワードを入力し、独立資格情報と署名鍵を生成します。既存 `.env` は上書きしません。モデル、OIDC、MCP、Code Runtime、互換パラメーターを最初からすべて設定する必要はありません。[設定参考、英語](../en/configuration.md)で時期と空値の意味を確認してください。

新環境は[日本語クイックスタート](../../../README_JA.md#クイックスタート)を使用します。既存データベースでは初期管理者を再生成せず、移行と通常管理を行います。

Definition は安定した Agent、Version は不変の公開版、Installation は会社内のインストール、Deployment は実サービス、Policy Snapshot は 6 種類の公開方針です。イメージ、健康なサービス、active なインストール、実行可能ユーザーは別の事実です。

ユーザーとワークロードは個別に認可されます。管理者には自動の実行権限がありません。会社管理者は部門の Agent 上限を設定し、部門管理者は範囲内で他メンバーへ利用権を付与します。最終確認には通常ユーザーの正しい実行、未許可ユーザーの拒否と、必要なキャンセル・復旧の証拠が必要です。

## コード助手への依頼例

```text
AgentPlug の agentplug-business-agent skill を使い、指定業務 Agent を開発・審査してください。
SDK 再利用、機能不足、実行テストを確認し、実際の会社・部門・ユーザーへの配信計画を準備してください。
許可した範囲でデプロイと権限設定を行い、通常ユーザーの実行と未許可ユーザーの拒否を検証してください。
秘密情報を含めず、未実施項目を成功として報告しないでください。
```
