## 补验和复现

全部用例、源码位置、原始跳过原因、条件、单项影响和日志 SHA-256 见[83 项机器回执](conditional-tests-verification-20261023.json)。原始私有日志与旧失败记录保存在本项目忽略目录；不上传凭据、业务数据库或私有日志。公开回执保留摘要与哈希，GitHub 新 job 仅上传明确的脱敏报告。

71 项专用 SQL 使用 6 个互相隔离的新数据库。Go 固定为 `1.26.10-bookworm`，开启 race detector；Go 容器仅与本轮自有 PostgreSQL 共享网络命名空间，没有 Docker 控制接口。缓存、签名与暂停进程测试的数据库断网；通信测试也断网，仅使用容器内真实回环连接。

规模测试实际创建 10003 个用户、90003 项角色绑定、10000 项资源授权；20 并发，每项操作 500 样本，列表 p95 **77.72 ms**，权限决策 p95 **15.71 ms**，达到现有测试阈值。数字属于本机隔离夹具，不外推线上性能。
