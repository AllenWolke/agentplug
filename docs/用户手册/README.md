# AgentPlug 使用手册

[English guide](README.en.md)

这份手册按你要完成的事情组织。先确认登录后的公司工作空间和所在部门，再选择可用助手；第一次使用可从一个示例问题开始。公司管理员的“管理部门”可以包含多个部门，这些部门仍属于同一家公司。“高级接入配置”中的接入范围供部署排障使用，不是另一家公司或部门。

在控制台左侧选择“开始使用与帮助”，也能看到与当前账号权限相符的操作说明。页面没有某个入口，可能是当前身份无权办理；不需要通过切换浏览器中的角色标签来取得权限。

登录页和控制台右上角都有明显的 **中文 / English** 按钮。点击即可切换界面语言，浏览器会记住选择。切换不会清空正在填写的内容或重新提交任务；业务数据、账号名称、资源编号和助手原始回答保持原文。新填入的示例按当前语言生成。

## 当前版本能做什么

业务用户可以在获准的工作空间使用助手、核对结果、查看本人运行历史和申请权限。管理员可以配置成员关系、岗位与资源授权，办理申请，并在授权范围内治理助手、模型和策略。

管理员可在用户列表跨页选择同公司账号，批量分配部门身份或开通 Agent 基础使用；也可批量办理待审批申请。每批最多 50 项，先预览每人的影响，再确认办理。结果逐项保存；中断后查询原批次，再选择继续或停止剩余项。精细资源、分享、导出等能力仍可单独配置，详见[权限与成员办理](权限与成员办理.md)。

可用性由账号、成员关系、岗位、具体资源、数据范围、期限、策略与部署共同决定。管理权不会自动取得业务使用权，登录成功也不代表可以访问所有助手或资料。

本文对应控制台现有功能。具体权限以服务端当前结果为准；演示数据、交互原型和服务健康不能作为实际业务验收结果。
